# 자비경 (메타 숫타) 팔리어 연구 앱

> **"허공을 씹어라!"** - 백봉 김기추 거사

## 📦 저장소

- GitHub: https://github.com/snailblu/metta-sutta

## 🌟 비전

**"매일 닦는 마음의 거울"**

부모님이 매일 빨리어 경전을 공부하고 수행하는 **가장 직관적이고 신뢰할 수 있는 도구**.

## 🎯 타겟

- **76세 사용자** (보림선원, 백봉 선생님 제자)
- IT 중상 (유튜브/웹서핑 자유로움)
- 기존: 영문 Pali Reader 사용 중

## 🚩 해결할 문제

1. **언어 장벽** - 한국어 직역 교재 부재
2. **신뢰성** - 출처 불분명한 번역
3. **접근성** - 매일 켜기 쉬운 모바일 도구

## 🛠 기술 스택

| 항목 | 기술 |
|------|------|
| **프레임워크** | Next.js 14 (App Router) |
| **스타일** | Tailwind CSS |
| **상태 관리** | Zustand |
| **로컬 저장** | IndexedDB (Dexie.js) |
| **LLM** | Gemini 3.0 Flash |
| **데이터 소스** | SuttaCentral |
