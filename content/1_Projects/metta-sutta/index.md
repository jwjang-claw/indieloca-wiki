# 자비경 (메타 숫타) 팔리어 연구 앱

> 팔리어 경전을 한국어로 직접 연구하고 수행의 의미를 깊이 탐구하는 도구

## 📦 저장소

- GitHub: https://github.com/snailblu/metta-sutta

## 🎯 목표

- 76세 사용자(부모님)를 위한 최적화된 UI
- 팔리어 원문 + 한국어 번역 대응
- 단어 상세 분석 (품사, 어근, 의미)
- PWA 지원 (오프라인 사용)

## 🛠 기술 스택

- Next.js 14 (App Router)
- Tailwind CSS
- Zustand (상태 관리)
- Dexie.js (IndexedDB)
- Claude API (AI 해설)
