## Phase 2: AI 해설 기능 (v2)

**기간:** 2026년 2월~3월 (빠르게)

**목표:** 사용자가 임의의 빨리어 구절을 입력하면 AI가 해설

### 기능

| 기능 | 설명 |
|------|------|
| **구절 입력** | 사용자가 빨리어 구절 복사 & 붙여넣기 |
| **AI 해설** | Gemini 3.0 Flash로 직역 + 문법 해설 |
| **비교 분석** | 다른 번역(영문/한글)과 비교 |
| **백봉 스타일** | 선적, 직관적인 우리말 해설 |

### 기술 스택

| 항목 | 기술 |
|------|------|
| **LLM** | Gemini 3.0 Flash (API) |
| **데이터 소스** | SuttaCentral (참고용) |
| **프론트엔드** | Next.js 14 |

### 성공 기준
- 부모님이 "이거 좋다"고 하심
- 해설이 정확하고 이해하기 쉬움
