## v2: AI 해설 기능

### 1. 구절 입력

```
┌─────────────────────────────────┐
│  빨리어 구절을 입력하세요        │
│  ┌───────────────────────────┐  │
│  │ Pāmojjaṃ...               │  │
│  └───────────────────────────┘  │
│         [해설 받기]             │
└─────────────────────────────────┘
```

**기능:**
- 텍스트 붙여넣기
- 길이 제한 (500자?)
- 빨리어 자동 감지

### 2. AI 해설 (Gemini 3.0 Flash)

**출력 형식:**

```
┌─────────────────────────────────┐
│ 📜 원문                          │
│ Pāmojjaṃ passaddhiṃ...          │
│                                  │
│ 🇰🇷 백봉 스타일 번역              │
│ "기쁨을 놓아라. 고요함을 보라..." │
│                                  │
│ 📖 단어 해설                     │
│ • Pāmojja = 기쁨, 환희           │
│ • Passaddhi = 고요함, 평정       │
│                                  │
│ 🧘 수행적 의미                   │
│ 기쁨조차 놓아야 비로소 고요함이   │
│ 온다. 집착을 놓는 것이 수행이다.  │
│                                  │
│ 📚 다른 번역 비교                 │
│ • Thanissaro: "Rapture, calm..." │
│ • Sujato: "Joy, tranquility..."  │
└─────────────────────────────────┘
```

### 3. 백봉 스타일 프롬프트

**시스템 프롬프트:**

```
당신은 한국의 선(禪) 스승입니다.
빨리어 경전을 번역할 때 다음 원칙을 따르세요:

1. 직관적이고 힘 있는 우리말을 사용하라
2. "허공을 씹어라!" 같은 선적 언어 사용
3. 현학적 용어보다 수행자가 바로 쓸 수 있는 말
4. "마음을 닦는다" > "심수(心修)를 행하다"
5. 이론보다 실천을 강조하라

번역 톤:
- 존댓말 사용 (하십시오체)
- 짧고 명확한 문장
- 수행적 의미를 항상 포함
```
