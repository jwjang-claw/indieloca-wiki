# IndieLoca 2026: 로드맵 (The "Grand Plan")

**목표:** "번역가의 무기" -> "게임 번역 표준 플랫폼"
**전략:** "LQA 리포트 제공" -> "번역가 입소문" -> "개발자 도입".

## 🗺️ Phase 1. 검증: "번역가의 무기(Weapon)" (1~2개월)
**컨셉:** 툴 사용법 가르치지 말고, **'압도적 결과물(Quality Draft + LQA Report)'**을 줘라.
*   **타겟:** 태그/오버플로우 재작업에 지친 **게임 번역 프리랜서**.
*   **워크플로우:**
    1.  **접수:** 번역가가 작업한 파일(Ren'Py/엑셀)을 보낸다. (또는 작업 전 파일)
    2.  **초벌 (LLM):** (옵션) 캐릭터 페르소나와 맥락을 반영한 **고품질 초벌 번역** 생성.
    3.  **검수 (LQA):** IndieLoca 엔진으로 **태그 오류 + 오버플로우** 체크.
    4.  **납품:** "초벌 잡아드렸으니 검수/윤문만 하세요. 태그/UI는 완벽합니다."
*   **핵심 가치 (Wow Point):**
    *   **"재작업 0건"** (LQA 완벽).
    *   **"이거 기계번역 맞아?"** (페르소나 살아있는 초벌).
    *   **"꿀이네?"** (작업 속도 3배 증가).
*   **성공 지표:**
    *   LQA 리포트 발송 3건.
    *   번역가 피드백: "덕분에 납품 전에 오류 잡았어요!" / "다음 프로젝트도 초벌 부탁해요."

## 🏗️ Phase 2. 셀프 서비스: "LQA 툴 공개" (3~4개월)
**컨셉:** 번역가가 직접 돌려보고 싶어 할 때 문을 연다.
*   **타겟:** 얼리 어답터 번역가 / 소규모 로컬라이제이션 팀.
*   **기능:**
    1.  **Web Workbench:** 번역가가 직접 파일 올리고 실시간 LQA 확인.
    2.  **LQA 배지:** "IndieLoca Verified" 마크 부여 (포트폴리오용).
    3.  **유료화:** 월 1~2만원 (커피값) 또는 건당 과금.
*   **목표:** "IndieLoca 안 쓰면 불안해서 납품 못 하겠다"는 습관 형성.

## 🚀 Phase 3. 생태계: "개발자 유입" (6개월~)
**컨셉:** 번역가들이 쓰기 시작하면, 개발자들도 자연스럽게 따라온다.
*   **타겟:** 번역 퀄리티를 고민하는 인디 개발자.
*   **모델:**
    1.  **매칭:** "IndieLoca 인증 번역가에게 맡기세요(LQA 보장)."
    2.  **협업:** 개발자-번역가 실시간 협업 툴 제공.
*   **목표:** 게임 번역 업계의 표준 LQA 플랫폼 등극.

## 📌 당장 해야 할 일 (Phase 1 착수)
- [ ] **번역가 커뮤니티(트위터/카페) 공략:** "태그 오류 미리 잡아드림(무료 LQA) + 원하면 초벌도 해드림."
- [ ] **LQA 리포트 샘플 제작:** "이런 식으로 오류 잡아줍니다" 보여줄 예시 PDF/이미지.
- [ ] **파이프라인 테스트:** GLM 스크립트로 오류 검출 로직 확인.
