# 📋 에이전트 태스크 티켓 [006]

## 🎯 목표
**MS-1: "와우" 기술 스택**의 마지막 퍼즐인 **시각적 출력(오버플로우 스크린샷)** 기능을 구현하고 검증합니다.
번역된 텍스트가 게임 내 텍스트 박스를 넘어갈 경우, 이를 시각적으로 감지하여 "빨간 박스"로 경고하는 이미지를 생성해야 합니다.

## 🚩 관련 마일스톤
*   **대상:** [[01_Strategy/Milestones#MS-1|MS-1: "와우" 기술 스택]]
*   **성공 기준:**
    - [ ] **시각적 출력:** "오버플로우 스크린샷" 자동 생성 (긴 텍스트에 빨간 박스 표시)

## 📂 컨텍스트 & 리소스
*   **저장소:** `project-translation` (FastAPI 백엔드)
*   **리소스:** `resource/2. Freak Circus/script.rpy` (샘플 스크립트), `resource/2. Freak Circus/images/textbox.png` (가상의 텍스트 박스 이미지 필요, 없으면 생성)
*   **기술 스택:** Python `Pillow` (PIL) 또는 유사 라이브러리 활용 예상

## 🛠️ 요구사항 (단계별)
1.  **텍스트 측정 로직 구현/확인:**
    *   백엔드(`app/services/ui_simulator` 등)에 폰트 및 텍스트 박스 크기 기준 텍스트 길이 계산 로직이 있는지 확인.
    *   없다면 `Pillow` 등을 이용해 특정 폰트(나눔고딕 등) 기준 픽셀 길이 측정 함수 구현.
2.  **오버플로우 감지:**
    *   입력된 번역문이 지정된 width(예: 800px)를 초과하는지 판단.
3.  **이미지 생성 (Red Box):**
    *   배경 이미지(게임 스크린샷 또는 텍스트 박스) 위에 번역 텍스트 합성.
    *   오버플로우 발생 시, 텍스트 영역 주위에 **빨간색 테두리(Red Box)**를 그리는 기능 구현.
4.  **테스트:**
    *   의도적으로 긴 번역문("이 문장은 텍스트 박스를 넘어가도록 아주 길게 작성되었습니다...")을 입력하여 빨간 박스 이미지가 생성되는지 확인.

## ✅ 성공 기준 (완료 정의)
*   [ ] **기능 구현:** 텍스트 길이 측정 및 오버플로우 감지 로직 동작.
*   [ ] **이미지 생성:** 오버플로우 시 "빨간 박스"가 포함된 결과 이미지 파일 생성.
*   [ ] **샘플 확보:** 정상 텍스트 vs 오버플로우 텍스트 비교 이미지 1세트.
